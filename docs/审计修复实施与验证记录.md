### 最小链路额外发现并修复

- 模板原来硬编码 `resources/templates/*`，配置资源目录后仍崩溃；现在使用 `Gin.ResourcesPath`。
- bcrypt 边界收紧后，管理员创建表单没有初始密码，导致创建总失败；新增专属创建 DTO 和前端密码输入，编辑资料不要求密码。
- 原生登录仍限制密码最多 32 字符，与 72 字节 bcrypt 范围不一致；已修改并以 48 字节密码实际登录验证。

### 工具覆盖限制

部分 LSP 为 push-only 或超时，Rust 主机没有工具链（使用容器完成编译测试）；不能宣称全仓静态检查干净。
设置页的 8 条 unused 报告是脚本分析未识别 Vue 模板绑定；锁测试的 map-write 报告实际是独立索引 slice 写入、WaitGroup 后读取。
已按源码证据标注误报，无源码禁用注释；会话扫描器可能再次发布旧结果。

## 部署前必须处理的契约变更

1. API 与 hbbs 配置相同的至少 32 字节 JWT 密钥；不生成临时降级密钥。
2. 旧 MD5 密码不可再登录，需要授权重置；旧缺少要求 claims 的 JWT 需重新登录。
3. `app.token-expire` 仅接受时长字符串，例如 `168h`；不接受裸整数。会话固定过期，无 DB 自动续期。
4. 管理员创建用户必须设置初始密码，密码创建与重置范围为 8–72 字节。
5. 控制通道使用 Linux Unix socket；旧 TCP 控制端口配置删除，不提供不安全 fallback。
6. 启用 LDAP 后不本地降级；旧同名账户/没有 LDAP 来源的账户不会自动认领。上线前必须人工解决身份归属。
7. OAuth 不自动合并同邮箱账户；重复 provider/subject 或 user/provider 数据会阻止启动，必须先备份并明确处理。
8. 遥测写入要求设备绑定会话；上线前验证部署中的 RustDesk 客户端实际携带认证信息。
9. WS 必须通过 TLS 反代，不开放明文公共 WS 作为最终部署方案。
10. 不允许用旧镜像标签假装包含本轮修改；需构建本修订并完成剩余发布验收。
